## iPAN 1.0.0 正式版

为 iPhone 18 Pro 打造的 65:24 宽幅相机，致敬哈苏 XPan。

### 拍摄
- 24 / 28 / 35 / 48 / 100 / 200mm 六个焦段都能拍 65:24：以 48MP 拍摄，按实际像素裁切输出，不插值放大
- 默认输出苹果原生 HEIC，保留完整 EXIF
- 色彩：**HNCS**（仿哈苏自然色彩，默认）/ XPan 胶片 / 原色 / 黑白，另有可调的 XPan 暗角
- 调色盘：底色风格 + 色调/色彩二维盘 + 调色板强度，预览与成片一致
- 可变光圈（iPhone 18 Pro 主摄 f/1.48–f/4.0，iOS 27）：光圈优先，快门与 ISO 自动
- 水印：semi-utils 模板，默认不带品牌 Logo
- 双摄拼接（测试）：主摄 + 超广角同步曝光，拼出约 13mm 视角的 65:24

### 交互
- 默认横屏，布局参照 OPPO 相机：左侧液态玻璃工具栏，右侧焦段 / 模式 / 快门列
- 快门后负片显影动效（C-41 负片 → 显影成正片 → 飞入缩略图）
- **灵动岛互动**：按快门时灵动岛跟着「闪」一下；冲洗较久时从灵动岛展开负片缩略图和进度；保存完成后展开成片缩略图与分辨率，点按直接查看、分享；切换焦段 / 色彩 / 光圈和各种提示都从灵动岛弹出
- Camera Control 按键：完全按下拍照（音量键也可以），轻按调焦段、曝光补偿、色彩、光圈
- 成片预览支持分享 HEIC 原文件

### 系统要求
- iOS 26 及以上的 iPhone；可变光圈需要 iOS 27 和支持的机型；Camera Control 需要 iPhone 16 及以后机型
- 安装包未签名，需要自行签名（AltStore、SideStore、LiveContainer 等）

### 已知限制
- 灵动岛的位置系统不提供，按 126×37pt 估算；在 LiveContainer 等容器小窗里运行时改为在取景区上方显示
- 双摄拼接仍是测试功能，配准不理想时会退回平移或居中对齐
