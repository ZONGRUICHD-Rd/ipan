## iPAN 1.1.0 正式版

横屏界面全面换成哈苏 XPAN 机身风格（复刻 OPPO Find X9 Ultra 的 XPAN 模式界面）。

### 新界面
- 深灰相机机身：上下两道带梯形缺口的接缝，顶部 HASSELBLAD 铭牌
- 带边框的取景窗就是 65:24 画幅本身，窗内有旁轴取景器式的亮框线和四角框
- 右侧：竖排 iPAN 标识（点按切换 iPAN / 双摄拼接）、色彩风格卡片（点按展开 HNCS / XPan / Original / Mono）、金属快门、缩略图
- 左侧：左上设置；左下工具，展开后是调色盘、光圈、水印、暗角
- iPad 或竖向窗口继续使用上中下布局

### 新功能
- 曝光补偿：取景窗左侧刻度尺上下拖动调节（0.1EV 一档，带触感反馈），双击归零；用 Camera Control 调曝光时刻度尺同步
- 变焦圆钮改为倍率显示：1× / 1.2 / 1.5 / 2 / 4 / 8（对应 24–200mm）

### 保留
- 灵动岛互动、负片显影动效、HNCS 色彩、可变光圈、Camera Control、水印等 1.0.0 的全部功能

### 系统要求
- iOS 26 及以上的 iPhone；可变光圈需要 iOS 27 和支持的机型；Camera Control 需要 iPhone 16 及以后机型
- 安装包未签名，需要自行签名
